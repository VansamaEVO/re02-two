# 个人主页 v2（极简单文件版）

> HTML 入门练习作品 —— 单文件极简个人主页，纯 HTML + 内联 CSS 实现。

一个轻量级的个人主页页面：顶部 Logo 图片、几句个性化的文案、页面底部图片与 B 站链接。无任何框架与构建依赖，打开即用。

## ✨ 页面内容

- 顶部：个人形象图（外链图片，点击跳转）
- 中部：个性化文案（「一帆风顺 · 万事如意」等）
- 底部：图片展示 + 外部链接（Bilibili）

## 🚀 本地预览

直接双击 `index.html` 用浏览器打开即可，或使用任意静态服务器：

```bash
# Python
python -m http.server 8080
```

## 🛠 技术栈

- 纯 HTML5 + 内联 CSS（单文件，零依赖）
- 响应式 viewport 适配

## 📁 项目结构

```
re02-two/

```
